# 课程作业 AI 视频

公开署名：zs。视频在本地生成，旁白使用 Windows 已安装的普通话男声 Microsoft Kangkang，不模拟作者本人声音或形象。

流程：先运行 `01_storyboard.py` 读取锁定分析结果，运行 `02_synthesize.ps1` 生成各句 WAV，再运行 `03_make_video.py` 输出成片，最后运行 `04_verify_video.py` 完整解码核查并抽取关键帧。画面由 Pillow 绘制，数字来自现有成果，字幕依据各句音频的实际采样数对齐。

输出：`D:\vibecode\联想会\成果交付\09_AI视频_zs`。

Python 使用宿主现有运行时及 Pillow、NumPy。新增 imageio-ffmpeg 0.6.0 安装在本目录 `dependencies/`，仅用于视频编码，不改变原数据分析环境。Windows 语音调用需要电脑正常用户权限，受限执行环境可能无法调用已安装语音。

原始数据、旧分析结果与模型未作修改；核查保留原 590 份冻结文件指纹。分镜、实际时间轴和脚本保存在本目录，体积较大的编码日志、帧图和旁白分句位于 `work/`。
