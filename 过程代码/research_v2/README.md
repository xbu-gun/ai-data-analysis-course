# 第二轮优化研究

本轮首先核查数据来源、年份与财务指标，再回测网站实际使用的加权决策树。原始数据、v1 代码、模型和交付文件均保留。

- 交付目录：`成果交付/07_优化研究_v2/`。
- 本轮过程文件：本目录内的 `work/`、`logs/`。
- `protocol.json`：运行前固定的回测规则和核查范围。
- `v1_preservation_manifest.json`：v1 全部交付文件及主要代码的原始指纹。
- 主分析环境：`../.venv/Scripts/python.exe`。
- 大型原始 XLSX 抽查使用宿主附带 Python（已有 lxml、openpyxl）；不向原环境安装包。

网站回测不调参，不使用已终评的 2020—2021 年留出样本。报告会注明这属于历史训练期的发展性回测。来源比对不等于确认所有变量定义都无误。

`10_review_added_material.py` 只读比对用户补充的“新增”目录。全部 14,715 个文件均为原课程包中对应文件的逐字节副本，其中包含 6 个 Excel、26 个 Python 脚本和 20 个 PDF；未发现额外构建脚本或历史披露版本。完整比对清单和摘要保存在交付目录的 `04_新增资料核查/`。先运行该脚本，再运行 `08_synthesize_first_review.py` 可把复核结论汇入第一阶段报告；`09_verify_first_review.py` 核查原有实验和 v1 保留状态。

`11_review_older_course.py` 使用宿主附带 Python（已有 pypdf）单独核对其后补入的“AI数据分析课程资料 261023”。89 个文件中 83 个相同，6 个差异文件的 PDF/文本提取和逐行差异保存在本目录 `work/older_course_diffs/`。旧版说明、规则和脚本未增加财务构建证据。

## 全文主题对照

用户其后要求继续改进，新增全文对照按 `text_protocol.json` 执行。原首、中、尾方案保留。主结果种子预设为 42，43 和 44 只检验敏感性，不能按结果选取。

在现有项目环境中，依次运行：

1. `12_full_text_embeddings.py`：原 1,123 篇顺序等分、不重不漏，每块正文最多 510 词元；本地 BGE 向量归一化、平均、再归一化。指纹绑定缓存，按文档恢复进度。
2. `13_compare_full_text_topics.py`：先复现旧聚类，再运行全文主结果与两个敏感性种子；记录离群和主题变化、保存可定位的原文片段。可用 `--baseline-only` 先检查旧结果。
3. 结合主题代表词与原文，审阅 `text_topic_names_v2.json` 的描述性命名；该文件只影响解释，不影响聚类。
4. `14_report_text_comparison.py`：生成第二阶段报告和第二轮复现源码包。
5. `15_verify_text_comparison.py`：核查样本顺序、指纹、完整覆盖、原文定位、预设种子、资源文件及 v1 保留状态。
6. `08_synthesize_first_review.py`：更新交付入口，链接新阶段报告。

所有交付保存至 `成果交付/07_优化研究_v2/06_全文主题对照/`。过程缓存位于本目录 `work/`，原始文本不上传。源码包是本项目的研究增量，需配合既有 v1 代码、课程本地数据和原有成果复现，不包含数据或模型权重。解释时分别报告覆盖率、聚类稳定性和原文核验，不能把这些指标称为外部准确率。

`16_explain_culture_scores.py` 独立复算现有784词版文化得分，分解各词对维度总分的贡献，为每维前5词保存原文例证。`culture_context_review_v2.json` 是对25个目的性选取片段的AI语义初审，只用于揭示解释边界，不用于估计总体准确率，也不改变词典或得分。交付在 `07_文化指标解释/`。
